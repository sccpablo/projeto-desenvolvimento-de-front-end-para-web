Quiz de Bandeiras 🌎

Sobre o projeto

O Quiz de Bandeiras é um projeto desenvolvido como atividade acadêmica da disciplina de Desenvolvimento Front-End para Web, do curso de Análise e Desenvolvimento de Sistemas.
A ideia do projeto é testar os conhecimentos dos usuários sobre as bandeiras de diferentes países, por meio de um quiz com perguntas de múltipla escolha.
Em cada questão, é apresentada a bandeira de um país e o usuário precisa escolher a resposta correta entre quatro alternativas.

Como funciona?

O quiz possui 9 perguntas, cada uma relacionada a um país diferente.
As alternativas são organizadas da seguinte forma:
1 país com a resposta correta;
2 países do mesmo continente da resposta correta;
1 país de outro continente.

A ordem das perguntas e das alternativas é embaralhada, tornando cada partida um pouco diferente.

Funcionalidades

Quiz com 9 bandeiras de países diferentes.
Quatro alternativas de resposta por pergunta.
Embaralhamento aleatório das perguntas.
Embaralhamento das alternativas.
Identificação visual de respostas corretas e incorretas.
Bloqueio das alternativas após a seleção de uma resposta.
Exibição do progresso das perguntas.
Mensagem de conclusão ao acertar todas as perguntas.
Opção para reiniciar o quiz.

Para desenvolver o projeto, foram utilizadas as seguintes tecnologias:

HTML5: utilizado para criar a estrutura da página.
CSS3: utilizado para estilizar a aplicação e organizar os elementos visuais.
JavaScript: utilizado para desenvolver a lógica do quiz, criar as alternativas, embaralhar as perguntas e controlar as respostas dos usuários.

Como executar o projeto

Para utilizar o quiz, basta seguir estes passos:
Baixar ou clonar o repositório.
Extrair os arquivos, caso tenha feito o download.
Abrir o arquivo index.html em um navegador.
Começar a responder às perguntas.
Não é necessário instalar nenhum programa adicional para executar o projeto localmente.

Objetivo do trabalho

O objetivo deste projeto é colocar em prática os conhecimentos adquiridos durante a disciplina, principalmente na utilização de HTML, CSS e JavaScript.
Durante o desenvolvimento, foram trabalhados conceitos como manipulação do DOM, criação dinâmica de elementos, eventos, funções, arrays e lógica de programação.
